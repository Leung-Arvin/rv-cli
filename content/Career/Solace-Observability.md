# Solace — Software Developer Co-op, Observability

**September 2025 – December 2025 · Ottawa, ON**

Observability is the Discipline of being able to answer Questions about a System
You did not think to ask in Advance.

I designed SLOs and SLAs for the Microservices sitting behind the SAP and Boomi
White-label Products, working backwards from Datadog Traces rather than from
what We hoped the Numbers were.

I also migrated Production Java Microservices to Spring Boot 3.5 without
freezing Feature Branches, so Releases kept flowing while the Upgrade landed
underneath Them.

Two Things I am glad I caught. A customer-escalated Defect was stopping Admins
from fully revoking User Access — a Security Gap wearing the Costume of a UI
Bug. And Platform Icons had drifted across Products, so I consolidated Them into
Solace's Component Library and had the Result validated in UI/UX Audits.

The Change with the widest Blast Radius was a UI Standardization across five
Micro-Frontends. That One needed Manager Sign-off before Release, because It
reached 183 Developers.
