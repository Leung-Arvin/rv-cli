# About

I'm Arvin. I write Software, mostly the kind that has to keep running after
everyone goes home.

I like the unglamorous Parts — the Boundary between two Services, the Error Path
nobody tested, the Log Line that turns a four-Hour Outage into a ten-Minute one.
I got into this because a Deploy broke and I wanted to know why, and I have not
really stopped wanting to know why.

This Site is a Terminal because a Terminal is honest. There is no Hero Section
telling You I am **passionate about Innovation**. There is a Filesystem, and You
can read It in whatever Order You like.

Start with `cat Resume.md` if You are here for the formal Version, or `cd Blog`
if You would rather hear Me think out loud.
